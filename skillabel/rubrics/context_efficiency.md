# Rubric: context_efficiency

Grades whether the skill respects the context budget through progressive
disclosure: a lean always-loaded description, a body sized to the task, and
heavier material pushed into on-demand reference files rather than inlined.
Ground every finding in a cited line.

**A** — Description is a few tight sentences. The body covers the common path
and defers rare detail (edge-case flags, large tables, deep reference) to
bundled files loaded on demand. Nothing that could be a reference is inlined.

**C** — Reasonable overall but with avoidable weight: a somewhat long body, or
detail that should live in a reference file kept inline, or a description longer
than it needs to be. Costs more context than necessary but is not egregious.

**F** — Bloated: an oversized body dumps reference-grade material inline,
duplicates content, or carries a long description that sits in context every
turn. No use of progressive disclosure where it plainly applies.
